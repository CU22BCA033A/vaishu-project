Your expression data

A CSV or TSV file from the hippocampus. You can include every gene: only the panel genes are used. Values must be log2 and normalized the same way as the reference.

Which file layouts work?

Genes as rows (most common)

gene,patient_1,patient_2
ANKIB1,0.52,1.31
RAE1,2.61,1.98
APP,1.20,1.18

Samples as rows

sample,group,ANKIB1,RAE1,...
P1,control,0.52,2.61,...
P2,AD,1.31,1.98,...

If a gene appears on several rows (several probes), the row with the highest average is used. Download the example file.
