Score hippocampus samples with a 7-gene panel

Upload gene-expression data from hippocampus tissue. The site picks out 7 genes that differed between Alzheimer’s and control brains in the GSE48350 dataset and gives each sample a score: positive means its pattern leans toward the Alzheimer’s group, negative toward the control group.

{% if validation %}

Current status of the panel: on an independent dataset (GSE5281, {{ validation.n_control + validation.n_alzheimers }} hippocampus samples) the panel did not separate Alzheimer’s from controls (AUC {{ "%.2f"|format(validation.auc) }}; 0.5 would be a coin flip). See the validation.

{% endif %}

This is a course project, not a medical test. The panel was built from 37 post-mortem samples and needs brain tissue, so it cannot be used on living people.

Group names that are recognised: control / normal / healthy, and Alzheimer / AD / case. With at least 3 of each, the results page also shows how well the panel separates them. If a gene has several rows (probes), the row with the highest average is used.
