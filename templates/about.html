How the score is calculated

The calculation lives in one short Python function, score_sample() in analysis.py. Here is what it does, step by step.

1. Pick out the panel genes

An expression file may have 20,000 genes. The site keeps only the 7 panel genes. If a gene appears on several rows (several probes on the chip), it keeps the row with the highest average, which was the same rule used to build the panel.

2. Compare each gene with a baseline

Each gene gets a z-score: how many standard deviations it is above or below a baseline.

z = (value − baseline_mean) / baseline_sd

There are two choices for the baseline:

  • The GSE48350 controls. The mean and SD of 18 control brains, stored in panel_reference.csv. Use this only for data processed exactly like GSE48350. Data from another lab is usually on a different scale and gets meaningless scores.
  • Your own batch. The mean and SD of all the samples you upload (at least {{ min_batch }}). This cancels out most lab and processing differences. The score then means “compared with the rest of this batch”, so the batch must contain both kinds of samples.

3. Point every gene the same way

Some panel genes are higher in Alzheimer’s and some lower. Multiplying by the gene’s sign (+1 or −1) makes “toward Alzheimer’s” positive for all of them.

contribution = sign × z

4. Average and compare with a cutoff

panel score = average of the contributions

A score above the cutoff is called “Alzheimer’s-like”. With the GSE48350 controls the default cutoff is {{ default_cutoff }}, the 95th percentile of the control scores. In batch mode it is 0, the batch average.

5. Check against labels (optional)

If you add a group column or row, the site measures how well the scores separate your groups (AUC, accuracy, sensitivity, specificity). The labels are only used for this check, never for the scores.

Limitations

  • The panel was chosen on 37 samples and did not replicate on GSE5281.
  • In GSE48350, disease status and processing batch overlap.
  • It needs post-mortem brain tissue, so it cannot be used on a living person.
  • It is not a diagnosis. Alzheimer’s disease is diagnosed by doctors with clinical tests.
