How it works

From a big expression table to one number

The scoring itself is one short Python function, score_sample() in analysis.py.

1

Find the panel genes

Your file can hold 20,000 genes. The site keeps only the 7 panel genes. If a gene has several probes, the one with the highest average is used.

2

Compare with controls

Each gene gets a z-score: how many standard deviations it is away from the average of 18 healthy control brains.

z = (value − control_mean) / control_sd
3

Point in the right direction

Some genes go up in Alzheimer’s and some go down. Multiplying by the sign makes “toward Alzheimer’s” always positive.

contribution = sign × z
4

Average and compare

The panel score is the average contribution. Above the cutoff ({{ default_cutoff }} by default) the sample looks Alzheimer’s-like.

score = mean(contributions)

Limitations, in plain words

  • Small dataset. The panel was found in only 37 post-mortem hippocampus samples (18 control, 19 Alzheimer’s).
  • Batch overlap. In that dataset disease and processing batch overlap, so some of the signal may come from how samples were processed.
  • Not validated. The panel has not been tested on independent data, so accuracy on new samples is unknown.
  • Same scale needed. Your values must be log2 and normalized like the reference. Otherwise the z-scores are meaningless (the site flags this as “scale looks off”).
  • Not a diagnosis. The output says which group a sample resembles in this one dataset. Alzheimer’s disease is diagnosed by doctors using clinical tests.
