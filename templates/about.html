Method

From an expression table to one score

The core calculation is a short Python function, score_sample() in analysis.py. Here is what it does, step by step.

{% endblock %} {% block content %}
1

Pick out the panel genes

An expression file can hold 20,000 genes. Only the 7 panel genes are kept. If a gene appears on several rows (several probes on the chip), the row with the highest average is used, which is the same rule used to build the panel.

2

Compare each gene with a baseline

A z-score says how many standard deviations a value is above or below a baseline.

z = (value − baseline mean) / baseline SD

GSE48350 controls: the mean and SD of 18 control brains, stored in panel_reference.csv. Use this only for data processed exactly like GSE48350.

Your own batch: the mean and SD of all uploaded samples (at least {{ min_batch }}). This cancels most lab and processing differences. A score then means “compared with the rest of this batch”, so the batch must contain both kinds of samples.

3

Point every gene the same way

Some panel genes go up in Alzheimer’s and some go down. Multiplying by the gene’s sign makes “toward Alzheimer’s” positive for all of them.

contribution = sign × z   // sign = +1 or −1
4

Average, then compare with a cutoff

score = average(contributions)

Above the cutoff means Alzheimer’s-like. The default is {{ default_cutoff }} with the GSE48350 controls (the 95th percentile of their scores) and 0 in batch mode (the batch average).

5

Check against labels

With a group column or row (at least 3 controls and 3 Alzheimer’s), the site reports AUC, accuracy, sensitivity, specificity and an ROC curve. Labels are only used for this check, never for the scores.
